Guion de demo de 2 minutos. Toca cada paso: los botones te llevan a la pantalla y escriben la frase por ti.

Todo se guarda en este navegador (IndexedDB). «Reiniciar demo» borra lo que hayas hecho y vuelve a los datos de Quirino. El micrófono necesita HTTPS: abre este archivo desde un enlace publicado, o usa «Escribir la frase».
