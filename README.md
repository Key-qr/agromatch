# AgroMatch 🌾 — Habla, registra y gana

Asistente de rentabilidad e inclusión digital para pequeños productores.
Proyecto para la hackatón **AGROTECH Challenge 2026** (UPN Trujillo · Perú Tech Week), **Desafío 03**.

**Demo en vivo:** https://key-qr.github.io/agromatch/

## Estructura

| Carpeta / archivo | Qué es |
|---|---|
| `agromatch/` | Código fuente de la PWA (React + Vite + Tailwind + Dexie). Ver su [README](agromatch/README.md). |
| `docs/` | Demo compilada en un solo HTML, publicada con GitHub Pages. |
| `AgroMatch_v2_Alineado_Desafio3.md` / `.docx` | Documento de la propuesta alineada al desafío. |
| `AgroMatch_Circular_Propuesta_y_Flujo_Hackaton.pdf` | Propuesta y flujo de la solución. |
| `Desafio escogido.jpg` | Ficha del desafío elegido. |

## Correr en local

```bash
cd agromatch
npm install
npm run dev      # http://localhost:5173
```

> Todos los datos de la demo son simulados y se guardan solo en el navegador (IndexedDB).
